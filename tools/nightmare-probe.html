Nightmare probe

Asks the Nightmare app on this phone which commands its API has, so Chatbox can paint with it. Your token is only sent to Nightmare on this phone (127.0.0.1) and isn’t saved or shown in the results.

In Nightmare: Settings › Advanced, turn on “Listen on the local network” and “Allow browser pages”.

Step 3: list models (v6)

Shows Nightmare’s full model and flow lists, so Chatbox can offer every model you’ve installed. Reads only; nothing is painted.

Step 2: test a picture

Paints six small test pictures of a red car on a beach, each sending the prompt a different way, to find the way Nightmare reads it. Takes about a minute.
